# Changelog

All notable FabricAssist changes are documented here.

The canonical release identifier is the stable Git tag (`vMAJOR.MINOR.PATCH`).
The root `VERSION` file and published package metadata mirror the latest stable
tag.

## [Unreleased]

Changes for the next release will be added here before a new version is tagged.

## [1.2.0] — 2026-07-31

### Added

- Added multi-select mode to customer garment history.
- Added explicit confirmation before deleting multiple garment histories.
- Added localized English and Spanish bulk-deletion labels and tests.

### Changed

- Replaced the wide bulk-delete action with a compact, accessible trash icon.

## [1.1.3] — 2026-07-30

### Fixed

- Closed the garment-history list deletion dialog after successful deletion.

## [1.1.2] — 2026-07-30

### Fixed

- Removed identity confirmations that could block garment-history deletion.

## [1.1.1] — 2026-07-30

### Fixed

- Added the deletion confirmation flow to the web experience.

## [1.1.0] — 2026-07-30

### Added

- Added confirmed deletion of a complete garment history and its associated data.

## [1.0.0] — 2026-07-30

### Added

- Published the first stable FabricAssist release.
