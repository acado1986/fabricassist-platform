# Archived planning documents

This directory contains historical planning, inventory, and completed
implementation-task documents. They explain prior decisions and changes; they
are not current deployment instructions.

Use the active guides instead:

- [`../production/deployment.md`](../production/deployment.md) — stable
  production releases.
- [`../environment.md`](../environment.md) — current configuration reference.
- [`../feature-tasks/`](../feature-tasks/) — work that is ready or in progress.

Completed task records live under
[`implemented-tasks/`](implemented-tasks/). Archived material is retained for
project history and auditability. Do not use old provider, branch, release-tag,
or infrastructure examples as a source of truth.
