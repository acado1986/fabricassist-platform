# Archived planning documents

This directory contains historical planning and inventory documents from the
free-alpha implementation. They explain how the prerelease profile was built;
they are not current deployment instructions.

Use the active guides instead:

- [`../prerelease/`](../prerelease/) — current prerelease configuration and
  operations.
- [`../production/deployment.md`](../production/deployment.md) — stable
  production releases.
- [`../environment.md`](../environment.md) — current configuration reference.

The archived plan is retained for project history and auditability. Do not use
its old provider, branch, release-tag, or infrastructure examples as a source
of truth.
